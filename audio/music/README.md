# 배경 음악 (PS Control)

PS Control 상단의 **Music** 버튼이 트는 음원이다. 설정 → `Music · 배경 음악` 에서
**Source** 를 `올려 둔 음원` 으로 고르면 여기 파일을 돌린다.

## 넣는 법

1. mp3 파일을 이 폴더에 넣는다.
2. `music.json` 에 파일 이름을 적는다. 둘 다 된다:

```json
["warmup.mp3", "changeover.mp3"]
```
```json
[{ "file": "warmup.mp3", "title": "워밍업" }]
```

3. 커밋 · 푸시하면 GitHub Pages 로 나간다. 태블릿에서 새로고침 두 번.

## ⚠️ 알아 둘 것

- **콜이 나올 때 자동으로 줄어든다**(설정의 `콜 중` 값). 끄는 게 아니라 줄이는 이유는
  껐다 켜면 곡이 뚝뚝 끊기기 때문이다.
- **저작권은 직접 확인한다.** 방송(OBS)에 코트 소리가 안 섞인다고 확인받았지만
  (2026-09-20), 그 구성이 바뀌면 유튜브가 다시보기를 음소거할 수 있다.
- mp3 는 git 에 그대로 들어간다. 큰 파일을 많이 넣으면 저장소가 무거워진다 —
  한두 곡이면 충분하고, 목록을 길게 쓰고 싶으면 **유튜브 재생목록** 모드가 낫다.
- 이 폴더가 비어 있으면(기본) 파일 모드는 "음원이 없어요" 라고 말한다. 고장이 아니다.
